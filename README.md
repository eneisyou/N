# 第1部：文法編 (Grammar)

## 1. 文法一覧表

| 语法                         | 用法                                                                                                       | 接续方式                                                                           | 例句                                                                       |
| :--------------------------- | :--------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------- | :------------------------------------------------------------------------- |
| **～のなんのって**     | 用于强调程度极高，带有十分赞叹、感慨等强烈情感，意思是“别提有多……了”。                                 | 多接在表示情感、状态等的名词或动词连体形之后。                                     | この映画、面白いのなんのって。                                             |
| **～たて**             | 强调动作刚刚完成，呈现出刚刚做完某事的状态，可译为“刚刚……；刚……完”。                                 | 动词“た”形 + たて。                                                              | 新しい家を建てたてです。                                                   |
| **～ったら**           | 用于提起某个对象，针对此对象表达不满，埋怨，吐槽时，有“说起……就……”的意思。                           | 名词 + たら。                                                                      | あの人ったら、いつも遅刻する。                                             |
| **～ようになっている** | 东西设计成、制造成某种功能 / 形态。设计成……；做成……结构；装置成……多用于产品说明、机械、建筑、电器。  | 动词基本型、动词否定形 + ようになっている。                                        | ドアは閉めると自動的にかぎがかかるようになっています                       |
| **～わけだ**           | 难怪……；怪不得……。根据已知事实，顺理成章得出结论。有恍然大悟的语感，知道原因后，瞬间理解事情缘由。     | 简体形、形2 + な、名词+の+わけだ                                                   | 今日は寒いわけだ、昨日から寒波が来ているから。                             |
| **～どころか**         | 用于强调程度超出预期，形成强烈对比，意思是“别说……，连……也……”。                                     | 简体形（A2去だ·N去だ） + どころか                                                 | 彼は日本語どころか、中国語も全然話せない。                                 |
| **～ようじゃ**         | 表示批评，“继续保持这种状态的话，不会有好结果的”如果继续...                                              | 动词基本形、否定形 + ようでは · ようじゃ。                                        | そんなことをするようじゃ、成功はできない。                                 |
| **～ぶる**             | 表示“装出…样子；冒充…”，带有贬义色彩。                                                                 | 名词，形1去い、形2+ぶる。                                                          | あの人は大企業の社長なのに少しも偉ぶったところがない。                     |
| **～に限って**         | 表示“唯独…；偏偏…”，强调特定的情况或对象，以及某个立场的人有某种倾向。                                 | 名词+に限って。                                                                    | ・今日に限って、バスが遅れた。・金持ちに限って、お金を出すのを嫌がるんだ。 |
| **～ことだ**           | 表示“应该…；最好…”，提出建议或劝告。                                                                   | 动词基本形、否定形+ことだ。                                                        | 早く寝ることだ。                                                           |
| **～という～**         | 前后接同一名词，用来指代某一类里所有的对象，全覆盖、没有例外，语气强调全部。                               | 名词+という+名词。                                                                 | この辺の木という木は、1本残らず燃えてしまった。                            |
| **～ところだった**     | 表示“差点…；几乎要…”，强调事情接近某种状态但未实现。                                                   | 动词基本形+ところだった。                                                          | 間に合わないところだった。                                                 |
| **～くらいなら**       | 表示“与其…不如…”，用于比较两种情况，选择更有利或更合适的。                                             | 动词基本形+くらいなら。                                                            | 行くくらいなら、死ぬほうがましだ。                                         |
| **～ましだ**           | 表示“…还好；…比较起来还算…”，用于比较两种不好的情况，选择相对较好的。                                 | 作为2类形容词，常与~ほうが・~より・~だけ・まだ・ずっと 连用                        | 病気になるましだ、死ぬよりはましだ。                                       |
| **～ものがある**       | 表示不由得让人产生某种感觉、深有…之感，用于抒发主观感受、感慨。                                           | 简体形（形2+な，不接名词）ものがある（只接现在时）。                               | 彼の絵には素晴らしいものがある。                                           |
| **～まい**             | 表示“不打算……；不会……”，表达说话者的决心或推测不会发生某事。                                         | 接续见下表（副表）                                                                 | ・こんな失敗を繰り返すまい。・雨が降っているから、彼はもう来るまい。       |
| **～につけ**           | “每当…就…”，自然产生某种情绪、感慨、回忆、想法。触景生情、有感而发，常搭配喜怒哀乐、怀念、感慨等心情。 | 名词 + につけ动词基本形 + につけ。                                                 | 朝になるにつけて、寒さが厳しくなる。                                       |
| **～わりに（は）**     | 表示“虽然……但是……；与……相比……”，用于对比前后两种不同的情况。                                     | 名词 + の、形2 + な+ わりに（は）简体形 + わりに（は）。                           | 彼は若いわりに、考え方が成熟している。                                     |
| **～か～かのうちに**   | 刚要做 A、还没完全做完 A 的时候，紧接着就发生了 B。强调前后动作间隔极短、接连发生。                        | 动词基本形 + か + 动词否定形 + かのうちに。（同一个动词）                          | 行くか行かないかのうちに、時間が過ぎていった。                             |
| **～げ**               | 接在动词连用形、形容词词干后，表示“看起来……；仿佛……”，是对事物外观、状态的推测。                     | 动词连用形 + げ；形容词词干 + げ。                                                 | 彼女は寂しげな顔をしていた。                                               |
| **～やら～やら**       | 表示“……啦……啦；又是……又是……”，用于列举多个事物或情况，带有一种列举不尽、杂乱的感觉。             | 名词 + やら + 名词 + やら动词原形 + やら + 动词原形 + やら形1 + やら，形1 + やら。 | 本やらノートやらが机の上に散らかっている。                                 |
| **～かと思うと**       | 表示“刚……就……”，强调动作或情况发生的迅速、连贯。                                                     | 动词过去形 + かと思うと。                                                          | 雷が鳴ったかと思うと、雨が降り出した。                                     |
